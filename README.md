# Hostel Management System

## Overview
The **Hostel Management System** is a web-based application designed to manage hostel operations efficiently. It allows students to book rooms, check availability, and manage profiles, while administrators can manage hostel data and monitor occupancy.

---

## Features

### Student
- Book a hostel room
- Check room availability
- View and update full profile
- Change password
- Forgot password functionality

### Admin
- Dashboard to monitor hostel occupancy
- Manage student bookings
- Update hostel information
- View access logs

---

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP
